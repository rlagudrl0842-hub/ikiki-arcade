아이키키 오락실 오류 수정 파일

사용 방법: 압축을 풀고 프로젝트 최상위 폴더에 파일을 덮어쓰기/추가하세요.

수정한 기존 파일:
- play-n2.js: 틀린그림 찾기 칸 배치와 대비, 승부차기 공 애니메이션, 3D 실패 시 2D 복귀
- play.css: 틀린그림 찾기 좌우 화면 색 구분, 모바일 게임 입력 영역 높이 조정
- admin.js: 결과 화면 재경기 선택 노출, 탭 전환 시 스크롤 위치 보존
- server.js: 동적 3D 모듈을 브라우저에 제공하도록 공개 파일 목록 추가
- pen3d.js: 골 장면의 공이 골대 앞에서 멈추지 않고 네트 안으로 이동

함께 추가하는 3D 실행 파일:
scene3d.js, g3d.js, three-0.160.0.min.js 및 게임별 3D 모듈 11개.
이 파일들은 play-n2.js의 동적 import에 필요하며, 일부는 원본 통합 ZIP에 포함되어 있지 않았습니다.

확인: JavaScript 전체 파일 node --check 통과. 실제 iPhone/iPad/Galaxy/PC 기기 실행은 하지 않았습니다.
