# ⚡ 아이키키 팀 대항 오락실

QR로 들어와서 스마트폰으로 즐기는 **실시간 팀 대항 미니게임 39종** 행사 웹앱.
유아체육 수업, 어린이집·유치원 행사, 초등 운동회, 학부모 참여수업, 연수·워크숍·송년회용.

- 앱 설치·회원가입 없음 — QR 찍고 이름만 쓰면 참가
- 참가자 폰 / 진행자 화면 / 대형 화면(프로젝터) 3개 화면이 서버로 실시간 연동
- 점수는 전부 **서버에서 계산·검증** (폰이 보낸 점수 숫자는 믿지 않음)
- 유아·초등·성인·전 연령 혼합 모드, 2~16팀, 300명 부하 테스트 통과

## 화면 3개

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `/admin.html` | 진행자 (노트북·폰) | 행사 만들기, 게임 순서, 시작/종료/일시정지, 팀·참가자 관리, 점수 수정, 결과 다운로드 |
| `/screen.html?e=코드` | 프로젝터·TV | QR 참가 화면, 게임 설명(음성), 카운트다운, 게임별 실시간 화면, 결과, 시상식 |
| `/play.html?e=코드` | 참가자 폰 | 이름·팀 선택, 게임 조작, 내 결과, 응원 버튼 |
| `/solo.html` | 진행자 혼자 | 🎮 혼자 테스트하기(나 vs 컴퓨터) · 👀 게임 미리보기(컴퓨터 vs 컴퓨터). 사회자 화면에서 열림 |

## 실행 방법

### A. 행사장 노트북에서 바로 (같은 와이파이)
1. [Node.js 22 이상](https://nodejs.org) 설치
2. 윈도우: `실행하기_윈도우.bat` 더블클릭 / 맥: `실행하기_맥.command` 더블클릭
   (또는 터미널에서 `npm install` → `npm start`)
3. 처음 실행하면 **관리자 비밀번호**가 화면과 `data/ADMIN_PASSWORD.txt`에 나와요
4. 진행자 화면 → 행사 만들기 → [설정] 탭 **참가 주소**에 실행 창에 나온 `같은 와이파이 접속 주소`(예: `http://192.168.0.15:8080`)를 넣기
5. **🖥 대형 화면 열기** → 프로젝터 쪽으로 옮기고 한 번 클릭(소리 켜기·전체 화면)

> 참가자 폰이 노트북과 **같은 와이파이**에 있어야 해요. LTE로 들어오게 하려면 B 방법.

### B. 인터넷에 올리기 (LTE·5G 접속)
실시간 WebSocket 서버가 계속 켜져 있어야 해서 Netlify 같은 정적 호스팅은 안 됩니다.

- **Render.com (추천)**: 이 폴더를 GitHub에 올리기 → Render → New → Blueprint → 저장소 선택 → `ADMIN_PASSWORD` 입력.
  `render.yaml`이 들어 있어요. 점수 저장용 디스크 때문에 유료 Starter 플랜(월 약 $7 + 디스크 1GB)이 필요합니다.
- Fly.io / Railway / 국내 클라우드 VM: `Dockerfile` 사용, `/data` 볼륨 연결
- 배포 후 [설정] 탭 참가 주소에 배포 주소 입력 (예: `https://ikiki-arcade.onrender.com`)

환경변수: `PORT`(기본 8080), `DB_FILE`(기본 `data/arcade.db`), `ADMIN_PASSWORD`

## 새 기능 (6차: 폰 없는 체육 60종)

- 노트북 1대 + 빔프로젝터만으로 하는 체육·레크리에이션 게임 60종 (`pe2data.js` 게임 정의 · `pe2.js` 진행 규칙 · `screen-pe2.js` 대형 화면 · `pe2draw.js` 그림)
- 17가지 진행 방식: 따라 하기 · 신호 반응 · 순발력 · 기억력 · 릴레이/전진 · 줄다리기 · 공격/방어 · 탑 쌓기 · 구역 점령 · 빙고 · 전략 선택 · 폭탄 · 서바이벌 · 미션 · 가위바위보 · 표현/협동 · 토너먼트
- 모든 판정은 사회자 입력(③ 진행의 판정 패드). 카메라·센서·휴대폰으로 학생 움직임을 감지하지 않음
- 연령(영아~성인, 초등 저/고학년)에 따라 신호 속도·라운드 길이·미션 난이도와 화면 스타일(동화풍 · 아케이드 · e스포츠 네온 · 경기 중계풍)이 바뀜
- 교실 모드: 뛰기·점프·이동 동작을 제자리 동작으로 자동 대체, 체육관 전용 게임은 추천에서 제외
- 게임 시작 전 10~20초 튜토리얼(동작 · 성공 조건 · 점수 · 안전), [게임 시작]으로 건너뛰기
- ① 준비: 게임 카드 필터(연령·장소·유형·시간·검색·즐겨찾기) · 🪄 추천 구성(연령·인원·장소·시간·경쟁 강도·준비물 → 목표 시간에 맞춘 순서, 확인 후 적용)
- 혼자 테스트: 내 팀은 직접 판정 입력, 컴퓨터 팀은 난이도별 확률 시뮬레이션 (실제 움직임 감지 아님)

## 새 기능 (5차 추가: 행사 시간)

- **전체 행사 시간 자동 계산**: 게임을 넣고 뺄 때마다 바로 다시 계산. 게임 플레이(반복 판 포함) + 설명 + 참가자 준비 + 카운트다운 + 점수 발표·승리 연출 + 게임 사이 전환 + 시작 인사 + 최종 시상 + 여유(%)를 모두 더함. 게임 시간·판 수·설명 화면·결과 발표는 실제 설정값, 사회자 설명·준비·전환·인사·시상·여유는 고칠 수 있는 추정값
- **목표 시간**: 20·30·40·60·90·120분·직접 입력. 넘치면 반복 줄이기·시간 25% 줄이기·게임 빼기, 남으면 줄였던 시간 되돌리기·게임 넣기·2판으로 늘리기를 추천. [적용]을 누르고 확인해야 바뀜
- **상단 시간 막대**: 준비 중엔 예상 총 시간·목표·게임 수·초과/여유, 행사 중엔 경과·남은 게임·예상 종료·목표 종료·지연/여유. 2분 넘게 늦어지면 "예정보다 N분 지연 중입니다. 다음 게임 시간을 단축할까요?" 알림. 자세한 내역은 [⏱ 시간 상세보기]
- **반복 판 수**: ② 게임 순서 ⚙에서 같은 게임을 1~5판 반복

## 새 기능 (5차)

- **사회자 화면 3단계**: ① 행사 준비(행사 종류·팀·게임 고르기·예상 시간·혼자 테스트·행사 시작) → ② 게임 순서(한 줄 목록, ▶ 미리보기 · ⚙ 설정은 한 게임만 펼침 · ▲▼/끌어서 이동) → ③ 진행(현재 게임·팀 점수·남은 시간·시작/일시정지/다음/종료 크게). 나머지 탭은 [더보기]
- **자동 저장**: 게임 순서·시간·배점·음악을 바꾸면 바로 서버에 저장 (새로고침해도 그대로). 일괄 설정(모든 배점·시간·배경음악, 기본값으로 되돌리기)은 덮어쓰기 전에 확인
- **음악 관리**: MP3·WAV·M4A 여러 곡 한 번에 넣기, 이름 바꾸기, 분류(⚡스피드 🔥배틀 🎯집중 🎉신나는 🏆승리 🎵기타), 곡별 음량, 순서, 검색, 길이 표시, 미리듣기/멈춤, 승리 음악 고르기. 쓰던 곡을 지우면 추천곡·기본 빵빠레로 대신. 넣은 곡은 이 컴퓨터의 이 브라우저에만 저장 (다른 기기로 자동 이동 안 됨)
- **🎮 혼자 테스트하기 / 👀 미리보기**: 실제 대형 화면·참가자 화면·게임 엔진 그대로 띄우고 컴퓨터(🟢쉬움 🟡보통 🔴어려움 🟣랜덤)가 실제 조작으로 참가. 테스트 행사는 행사 목록·리그에 안 보이고, 종료하면 지워짐(남은 것도 하루 뒤 정리)
- **다음 게임 자동 준비**: 자동 진행을 꺼도 결과 다음엔 다음 게임 소개 화면까지 준비, 시작은 사회자가 눌러야 함 (③ 더보기에서 끌 수 있음)
- **실수 방지**: [지금 종료]·Space(게임 중)는 확인 후 실행. 대형 화면 창에서는 E를 2초 안에 두 번 눌러야 종료

## 새 기능 (4차)

- **퀴즈 베끼기 방지**: 골든벨 보기 순서를 참가자마다 섞고, 답을 내면 '제출 완료'만 표시, 공개 전에는 정답·정답률 비공개
- **문제 중복 방지**: 한 행사에서 낸 문제는 다 쓸 때까지 다시 안 냄, 재경기는 새 문제, 설명 화면에서 🔄 문제 바꾸기
- **재경기 점수 선택**: 점수 유지하고 다시 / 이 게임 점수만 지우고 다시 / 취소
- **⚡ 퀵 점수판**: 팀별 +단위·−단위·직접 입력·되돌리기·기록, 폰 리모컨에도 있음. 단축키 숫자 1~9(Shift = 빼기), U = 되돌리기 — 대형 화면 창에서도 동작
- **휴대폰 없이 진행**: 설정 → 진행 방식. 대형 화면에 게임·규칙·타이머, 점수는 진행자가 입력. 골든벨은 종이·보드로 동시 공개
- **참가**: QR 없이 참가 코드 입력(`/join`), 이름을 비우면 참가 번호, 진행자가 👥 탭에서 직접 등록
- **인터넷 없이**: 노트북에서 `실행하기_윈도우.bat` / `실행하기_맥.command` (Node.js는 미리 설치). 같은 공유기·핫스폿의 폰은 노트북 주소로 접속

## 점수 규칙
- 게임마다 각 참가자 기록을 **0~100점으로 환산** (연령별 기준이 달라 혼합 모드도 공정)
- 팀 점수 방식: 팀 평균(기본) / 합산 / 대표자 / 상위 N명 평균
- 게임 순위 → **순위 포인트** = (팀 수 − 순위 + 1) × 10 × 배점. 동점은 같은 순위·같은 포인트
- 원래 기록(게임 기록)과 순위 포인트는 따로 저장
- 응원은 기본적으로 점수와 무관. 진행자가 **응원 이벤트**를 열면 1인당 응원 1위 팀에 보너스
- 역전 룰렛·응원 이벤트·수동 수정은 '보너스'로 따로 기록 (CSV에 사유와 함께)
- 종합 동점: 1위 횟수 → 게임 기록 합 순으로 가림

```
games.js         게임 목록 (n1~n7.js 게임별 서버 판정, gen2.js·n3data.js 공용 데이터)
db.js            SQLite (node:sqlite 내장)
admin.* play.* screen.*   진행자 / 참가자 폰 / 대형 화면 (빌드 없는 순수 JS)
play-n*.js screen-n*.js   게임별 폰 조작 화면 / 대형 화면 연출
bgm.js + bgm-*.mp3        배경음악 관리 (게임별 곡, 빵빠레, 내 MP3 넣기)
card.js                   결과 공유 카드
test/                     단위·회귀·300명 부하·폰 터치 시험
docs/                     관리자 사용 설명서, 테스트 보고서
```

### 명령서의 React + Supabase 대신 이렇게 한 이유
- **Supabase Realtime 무료 플랜은 동시 접속 200명·초당 메시지 100개 제한** (Pro도 500명·초당 500개) → 300명이 동시에 연타하는 게임을 감당하기 어려움
- 게임 판정(두더지 시간창, 탑 재계산, 반응속도 검증)을 **서버 메모리에서 즉시** 처리 → 터치마다 DB에 쓰지 않고 결과만 저장
- **행사장 노트북 한 대로 인터넷 없이도** 돌아감 (빌드 단계 없음, 설치 파일 2개)
- TypeScript·ESLint 대신 문법 검사 + 단위·통합·부하·브라우저 테스트로 검증

## 테스트
Node 22.13 이상 기준 (Render와 같음). `--experimental-sqlite`는 22.13 미만에서만 필요.
```bash
npm install
node --experimental-sqlite --test test/core.test.js test/regress.test.js   # 기본 기능 19개 + 이번 수정 회귀 6개
OLD_SERVER=<예전 server.js 경로> node --experimental-sqlite --test test/accounts.test.js test/signup.test.js test/teamrename.test.js
node --experimental-sqlite test/load.js 300 all 12          # 300명 × 35종 전체 진행 (결과: test-results/load-300.json)
node --experimental-sqlite test/new10.js mixed 24 4         # 24명 봇으로 전체 게임 빠르게
node --experimental-sqlite test/touch-server.js 4451 inputs.json   # 폰 터치 시험용 서버 (입력 수를 파일로 기록)
OLD_SERVER=<예전 server.js 경로> node --experimental-sqlite --test test/*.test.js   # 단위·통합 전체
```
폰 터치·사회자 조작·영상 녹화는 Playwright(파이썬) 스크립트로 했고, 결과는 `docs/TEST_REPORT.md`에 있습니다.
